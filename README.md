# Para Elina — 3 meses

Probar local: `python3 -m http.server 5517` dentro de esta carpeta y abrir http://localhost:5517 (código: 1111).

## Qué editar
- `js/config.js` → la carta, las frases, las palabras de la galaxia y los textos de las fotos.
- `fotos/` → foto1.jpg … foto6.jpg (verticales quedan mejor; idealmente menos de 500 KB cada una).
- `musica/Nuestro-Camino.mp3` → la canción.

## QR con forma de corazón
Abrir http://localhost:5517/herramientas/qr-corazon.html, pegar el link final de Vercel y tocar "Descargar PNG".
La carpeta `herramientas/` no se publica (ver `.vercelignore`).
